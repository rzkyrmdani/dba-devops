Penjelasan perintah:

-Fp (format plan) : Menentukan format output sebagai plain text.
-h localhost: Menentukan host database (dalam hal ini, localhost).
-U username: Menentukan nama pengguna yang akan digunakan untuk melakukan backup.
-p 5432: Menentukan port yang digunakan oleh PostgreSQL (port default adalah 5432).
-d dbname: Menentukan nama database yang akan di-backup.
-f /path/to/backup/dbname_backup.sql: Menentukan lokasi dan nama file untuk menyimpan hasil backup.

============================== cek semua table yang ada schema postgres dan jumlah count nya =======================

SELECT 
    t.table_name,
    COALESCE(s.n_live_tup, 0) AS row_count
FROM 
    information_schema.tables t
LEFT JOIN 
    pg_stat_user_tables s 
ON 
    t.table_name = s.relname
WHERE 
    t.table_schema = 'public';
