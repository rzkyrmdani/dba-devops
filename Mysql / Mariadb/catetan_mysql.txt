===================== Install MySQL ================================

- download repo dan install repo

wget https://dev.mysql.com/get/mysql-apt-config_0.8.33-1_all.deb
sudo dpkg -i mysql-apt-config_0.8.33-1_all.deb

- Update package list dan Install MySQL server + client

apt update
apt install mysql-server mysql-client -y

sudo systemctl enable mysql
sudo systemctl start mysql

- Amankan instalasi dan buat password root mysql
sudo mysql_secure_installation

===== allow remote mysql =========

- vi /etc/mysql/mysql.conf.d/mysqld.cnf

ganti bind-address            = 127.0.0.1
jadi ini bind-address            = 0.0.0.0

atau jika tidak ada tambahkan saja ip yang ingin di allow contoh
bind-address = 0.0.0.0

- selanjutnya
systemctl status mysql
systemctl restart mysql
systemctl status mysql

- buat user root dengan persen(%) agar connect ke semua ip 

CREATE USER 'root'@'%' IDENTIFIED BY 'Welcome@1234';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%';
FLUSH PRIVILEGES;

-Pastikan firewall mendaftarkan port mariadb/mysql

ufw allow 3306/tcp
ufw status

*jika firewall mati abaikan selanjutnya

- coba remote pakai tools seperti navicat dll

- "BILA ADA ERROR Public Key Retrieval is not allowed"

opsi 1
alter user dengan mysql_native_password
ALTER USER 'root'@'%' IDENTIFIED WITH mysql_native_password BY 'Welcome@1234';

alter user dengan caching_sha2_password
ALTER USER 'root'@'%' IDENTIFIED WITH caching_sha2_password BY 'Welcome@1234';

FLUSH PRIVILEGES;

opsi 2
allowPublicKeyRetrieval=true di navicat atau dbeaver
