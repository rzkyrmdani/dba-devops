===================== Install MySQL ================================

- download repo dan install repo

wget https://dev.mysql.com/get/mysql-apt-config_0.8.33-1_all.deb
sudo dpkg -i mysql-apt-config_0.8.33-1_all.deb

- Update package list dan Install MySQL server + client

apt update
apt install mysql-server mysql-client -y

sudo systemctl enable mysql
sudo systemctl start mysql

- Amankan instalasi dan buat password root mysql
sudo mysql_secure_installation

===== allow remote mariadb/mysql =========

- vi /etc/mysql/mariadb.conf.d/50-server.cnf

ganti bind-address            = 127.0.0.1
jadi ini bind-address            = 0.0.0.0

- selanjutnya

systemctl restart mariadb

- buat user root dengan persen(%) agar connect ke semua ip 

CREATE USER 'root'@'%' IDENTIFIED BY 'Welcome1';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%';
FLUSH PRIVILEGES;

-Pastikan firewall mendaftarkan port mariadb/mysql

ufw allow 3306/tcp
ufw status

*jika firewall mati abaikan selanjutnya

- coba remote pakai tools seperti navicat dll
